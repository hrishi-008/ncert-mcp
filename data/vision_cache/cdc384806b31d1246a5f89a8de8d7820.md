## 7.2 Solving Equations Systematically

How did you solve the various equations framed in the previous section? One way to solve an equation is to substitute different values in place of the letter-number and to check which value makes LHS = RHS. For example, consider the equation $2n + 1 = 99$.

If we substitute $n = 5$, we get LHS $= 2 \times (5) + 1 = 11$. It is far away from 99, the RHS.

We can try $n = 10$. The LHS is 21. It is still not equal to 99.

Can we try $n = 30$? The LHS is now 61, still much lower than 99.

Let us try $n = 40$. The LHS is 81. We are getting closer to 99.

When $n = 50$, the LHS is 101. This is just a bit too high.

When $n = 49$, the LHS is 99!

Therefore, the solution to the equation $2n + 1 = 99$ is $n = 49$.

Can this equation have any other solution?

This method is called the **trial and error** method.

The trial and error method can be inefficient.

Try solving $5x - 4 = 7$ using trial and error.
