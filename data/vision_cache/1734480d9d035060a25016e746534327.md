(i) If $n$ is odd, then $3n + 4$ is odd then some expressions of odd parity would be—
$5n + 2$, $9n + 4$ etc.
Some expressions of even parity — $2n + 4$, $4n + 6$ etc.

(ii) If n is even, then $3n + 4$ is even then all expression will be even parity —
$(5n - 2)$, $n + 4$ etc.

### Are there expressions using which we can list all odd numbers?

**Ans:** $2n$-1 is the expression that can list all odd numbers.

### **What would be the $n$th term for multiples of 2? Or, what is the $n$th even number?**

**Ans:** $2n$
