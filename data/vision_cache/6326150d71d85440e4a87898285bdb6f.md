As it is the sequence of multiples of 4, it can be seen that the nth term will be 4 times $n$:

$$4 \times n$$

As a standard practice, we shorten $4 \times n$ to $4n$ by skipping the multiplication sign. We write the number first, followed by the letter(s). Find the value of the expression $7k$ when $k = 4$. The value is $7 \times 4 = 28$.

Find the value that the expression $5m + 3$ takes when $m = 2$.

As $5m$ stands for $5 \times m$, the value of the expression when $m = 2$ is $5 \times 2 + 3 = 13$.
