*Explanation*

Recall the connection between addition and subtraction. For $3 + ? = 5$, we can find the missing number using subtraction: $5 - 3 = 2$. That is, subtraction is the same as finding the missing number to be added.

We know that—

**Starting Floor + Movement needed = Target Floor**

If the movement needed is to be found, then,

**Starting Floor + ? = Target Floor**

So,

**Target Floor – Starting Floor = ? = Movement needed**

*More examples:*

a. If the Target Floor is $-1$ and Starting Floor is $-2$, what button should you press?
You need to go one floor up, so, you should press $+1$.
Expression: **$(-1) - (-2) = (+1)$**

b. If the Target Floor is $-1$ and Starting floor is $+3$, what button should you press?
You need to go four floors down, so, you should press $-4$.
Expression: **$(-1) - (+3) = (-4)$**

c. If the Target Floor is $+2$ and Starting Floor is $-2$, what button should you press?
You need to go four floors up, so, you should press $+4$.
Expression: **$(+2) - (-2) = (+4)$**
